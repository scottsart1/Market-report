Key conventions

NBER timing. NBER dates recessions to months; onset here = first day of the first recession month. Day-level horizons are a modeling convention via the hazard term structure — the historical labels carry no daily precision.

Point-in-time discipline. Training features use ALFRED first-release values and actual release dates where vintages exist; configured publication lags otherwise. Residual revision bias is disclosed, not hidden. Today's inputs use latest revised data — correct for today's forecaster.

Uncertainty. With ~8 recessions of usable history, read ranges, not decimals: the band is a lower bound on true uncertainty.
